# WoWFN — فارسی‌ساز Forever (نسخهٔ نسل جدید)

افزونهٔ فارسی‌سازی برای World of Warcraft **Forever (Classic 1.15.x / 1.60.x)** — بازنویسی کامل و مستقل از WoWFarsi قدیمی، با معماری جدید.

وب‌سایت: https://wowfarsi.ir

## چه کاری می‌کند

- نمایش **نام و توضیح فارسی** زیر تولتیپ اسپل‌ها، استعدادها، آیتم‌ها، شخصیت‌ها و مأموریت‌ها
- **موتور متن فارسی**: فشرده‌سازی حروف (shaping)، اعداد فارسی، پشتیبانی راست‌به‌چپ در سه حالت
- فونت **Vazirmatn** همراه افزونه (مجوز SIL OFL 1.1)
- دکمهٔ مینی‌مپ، پنل تنظیمات کامل و دستورات اسلش `/wofn`
- **موتور امن**: هر هوک در `pcall` اجرا می‌شود؛ اگر یک ماژول خطا بدهد، تا پایان اجرا خاموش می‌شود و بازی هرگز کرش نمی‌کند

## نصب

۱. آخرین Release را از همین صفحه بگیرید یا پوشهٔ `WoWFN` را دانلود کنید.
۲. آن را در `Interface\AddOns\WoWFN` کپی کنید.
۳. بازی را اجرا کنید؛ دکمهٔ مینی‌مپ یا `/wofn` راهنما را نشان می‌دهد.

## دستورات

| دستور | کار |
|---|---|
| `/wofn panel` | پنل تنظیمات |
| `/wofn mode 1\|2\|3` | حالت نمایش متن فارسی |
| `/wofn size 8..22` | اندازهٔ فونت |
| `/wofn modules` | وضعیت ماژول‌ها و تعداد ترجمه‌ها |
| `/wofn toggle spells` | روشن/خاموش کردن یک ماژول |
| `/wofn debug` | نمایش خطاها |

## معماری

```
WoWFN/
├── Core.lua        بوت، SavedVariables، رجیستری ماژول، رپ امن هوک‌ها
├── Config.lua      دستورات اسلش
├── Text.lua        موتور متن: shaping، bidi، اعداد فارسی
├── Tooltip.lua     افزودن خط فارسی به تولتیپ‌ها
├── Data/Data.lua   جدول‌های ترجمه + MergeData برای پک‌های داده
├── Modules/        Spells، Items، Quests، NPCs
├── Panel.lua       پنل تنظیمات
├── Minimap.lua     دکمهٔ مینی‌مپ
└── Fonts/          Vazirmatn (OFL)
```

پک‌های ترجمه (فایل `WoWFN_ExtraData.lua` با همان اسکیمای جدول‌ها) با `N.MergeData` در زمان لود ادغام می‌شوند؛ ساخت داده‌ها با اسکریپت‌های `scripts/` انجام می‌شود.

## توسعه

- بررسی سینتکس: `luac5.4 -p WoWFN/**/*.lua`
- تست موتور متن: `lua5.4 tests/text_test.lua`
- ساخت Release zip: `scripts/release.sh <نسخه>`
